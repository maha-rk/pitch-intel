# Pitch Intel — Backend API

FastAPI backend for [Pitch Intel](https://github.com/maha-rk/pitch-intel).

Set the following Space secrets before running:
- `LLM_PROVIDER` = `watsonx`
- `WATSONX_API_KEY` = your IBM watsonx API key
- `WATSONX_PROJECT_ID` = your IBM watsonx project ID
- `WATSONX_URL` = `https://eu-de.ml.cloud.ibm.com`
